# My Playwright Automation Project

This is a test automation project using Playwright.

## Prerequisites
- Node.js (version 18 or higher)

## Installation
1. Clone the repository
2. Run `npm install` to install dependencies
3. Run `npx playwright install` to install the required browser binaries

## Running Tests
- To open Playwright UI Mode: `npx playwright test --ui`
- To run tests in headless mode: `npx playwright test`
- To view the HTML test report: `npx playwright show-report`
